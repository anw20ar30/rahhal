منصة رحّال – خطوات التثبيت على XAMPP

1
تحميل XAMPP

تحميل XAMPP من: https://www.apachefriends.org/download.html

تأكد من تثبيت: ✅ Apache   ✅ MySQL   ✅ PHP 7.4+   ✅ phpMyAdmin

2
نسخ ملفات المشروع

انسخ مجلد rahhal بالكامل إلى:

C:\xampp\htdocs\rahhal\
تأكد من أن index.php موجود مباشرة داخل مجلد rahhal
3
تشغيل XAMPP

افتح XAMPP Control Panel واضغط Start بجانب Apache و MySQL

4
إنشاء قاعدة البيانات

افتح المتصفح: http://localhost/phpmyadmin

  1. اضغط New من القائمة اليسرى
  2. اكتب الاسم: rahhal_db
  3. اختر: utf8mb4_unicode_ci
  4. اضغط Create
5
استيراد قاعدة البيانات
  1. انقر على rahhal_db ثم تبويب Import
  2. اختر الملف: rahhal\database\rahhal_db.sql
  3. اضغط Go
ستظهر 5 جداول: admins, users, categories, experiences, bookings
6
