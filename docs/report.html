شكر وتقدير

بسم الله الرحمن الرحيم، والصلاة والسلام على أشرف الأنبياء والمرسلين.

نتقدم بخالص الشكر والامتنان لكل من أسهم في إتمام هذا المشروع. نشكر الله سبحانه وتعالى الذي وفقنا لإتمام هذا العمل، ونشكر أستاذنا المشرف الكريم على توجيهاته القيّمة، وعائلاتنا على دعمهم المعنوي.

هذا المشروع إسهام متواضع في مسيرة التحول الرقمي لقطاع السياحة والضيافة في المملكة العربية السعودية.

الملخص التنفيذي

يُقدم هذا التقرير توثيقاً شاملاً لمشروع منصة رحّال، وهي منصة ويب عربية متكاملة تم تطويرها باستخدام XAMPP وPHP وMySQL وHTML5 وCSS3 وJavaScript وBootstrap 5.

تتيح المنصة للمسافرين استكشاف وحجز تجارب إقامة فريدة في أجمل وجهات المملكة العربية السعودية. تتبع المعمارية الثلاثية الطبقات وتوفر 6 وحدات وظيفية متكاملة.

الكلمات المفتاحية: منصة حجز، تجارب فندقية، PHP، MySQL، عربي RTL، XAMPP، Bootstrap 5.

١. المقدمة

في ظل التحول الرقمي المتسارع في المملكة العربية السعودية ضمن مستهدفات رؤية 2030، وتنامي قطاع السياحة الداخلية، باتت الحاجة ماسّة إلى حلول رقمية متطورة تخدم المسافر العربي.

منصة رحّال ليست مجرد موقع حجز فنادق تقليدي، بل هي بوابة رقمية لاكتشاف تجارب إقامة استثنائية تمزج بين الفخامة والأصالة في أجمل وجهات المملكة.

البيئة التقنية

  • PHP (Procedural): منطق الأعمال ومعالجة البيانات
  • MySQL: قاعدة بيانات علاقية
  • HTML5 / CSS3: هيكل الصفحات وتنسيقها
  • JavaScript: التفاعلية والتحقق
  • Bootstrap 5 RTL: تصميم متجاوب عربي
  • XAMPP: بيئة التطوير المحلية

٢. أهداف المشروع

  • توفير منصة عربية متكاملة لحجز التجارب الفندقية الاستثنائية.
  • تعزيز التحول الرقمي في قطاع السياحة الداخلية بالمملكة العربية السعودية.
  • بناء نظام إدارة محتوى متكامل للمشرفين.
  • تطبيق معايير الأمان الرقمي والحماية من الثغرات الشائعة.
  • تصميم واجهة مستخدم عربية جميلة ومتجاوبة.
  • توفير نظام بحث وفلترة متقدم.
  • بناء نظام حجز ذكي يحسب التكلفة تلقائياً.
  • توثيق المشروع توثيقاً أكاديمياً شاملاً.

٧. معمارية النظام الثلاثية الطبقات

يتبع مشروع رحّال نمط المعمارية الثلاثية الطبقات (3-Tier Architecture):

🖥️ طبقة العرض (Presentation Layer)
HTML5 · CSS3 · JavaScript · Bootstrap 5 RTL
⬆️ HTTP ⬇️
⚙️ طبقة منطق الأعمال (Business Layer)
PHP Procedural · Sessions · Includes
⬆️ SQL ⬇️
🗄️ طبقة البيانات (Data Layer)
MySQL · Prepared Statements · UTF8MB4

مزايا هذه المعمارية

  • الفصل الواضح بين طبقات النظام
  • سهولة الصيانة والتطوير
  • قابلية التوسعة والتعديل
  • الأمان عبر طبقة PHP كحاجز حماية
  • إعادة الاستخدام عبر PHP Includes
